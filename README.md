Project Name

PayEase – Mobile Banking App UI Design

Project Scope

PayEase is a mobile banking application UI design created to provide users with a simple and convenient digital banking experience. The design focuses on account access, money transfers, transaction tracking and profile management.

Project Objectives

- Design a user-friendly mobile banking interface.
- Simplify the money transfer process.
- Provide easy access to transaction history.
- Improve navigation and user experience.

Project Screens

1. Login / Sign Up Screen
2. Dashboard Screen
3. Send Money Screen
4. Transaction History Screen
5. Profile Screen

Tools Used

- Figma

Key Features

- User Login and Registration
- Account Balance Display
- Money Transfer
- Transaction History
- Profile Management
